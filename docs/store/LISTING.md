## Store listing

**Name:** TwinTabTracker

**Summary** (from the package description):

Find the tabs you need. Eliminate unnecessary duplicates. Keep your browser under control.

**Category:** Productivity

**Language:** English

**Detailed description:**

TwinTabTracker is a local-first tab manager. It helps you find an already-open tab, park pages you want later, and close extra copies of the same URL.

Park a tab in one click. TwinTabTracker saves the URL on this browser and closes the live tab. Click a parked row to open it again.

Cleanup never closes every tab in a duplicate group. Pinned tabs, the active tab, and the last tab in a window stay protected unless you change settings. Undo tells you which pages it will reopen.

Nothing is sent to a TwinTabTracker server. There is no account, no analytics, and no access to page content.

**Content rating:** Not mature

Skip the YouTube video and the 1400×560 marquee unless you want them later.

## Privacy practices

**Single purpose:**

Find open tabs, park URLs locally, and close extra copies of the same URL.

**Permission justifications**

- `tabs`: See which tabs are open, find duplicates, switch to an existing tab, and close selected extras.
- `storage`: Save settings, parked URLs, and cleanup history on this browser.
- `sessions`: Reopen a tab after cleanup when Undo is available.
- `contextMenus`: Add Park this tab to the tab and page menus.

**Remote code:** No

**Data collection:** Do not check location, health, financial, authentication, personal communications, or web history as if you send them anywhere. You store parked URLs, titles, and recent cleanup records locally only. Disclose that website URLs and titles can be saved on the device for parking and undo, are not sold, and are not sent to TwinTabTracker servers.

**Privacy policy:** the GitHub URL above.
