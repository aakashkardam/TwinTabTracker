# Security

TwinTabTracker is a local-only browser extension. It does not send browsing data to a TwinTabTracker server.

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/aakashkardam/TwinTabTracker/security/advisories/new) if available, or by opening a private report with the maintainer. Do not file a public issue for an unpatched vulnerability.

The extension uses `tabs`, `storage`, `sessions`, and `contextMenus` only. A report that it can read page content or inject scripts into websites is unexpected and should be treated as a bug.
